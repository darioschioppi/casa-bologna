# Note e diario visite/contatti

Usa questo file come diario libero per annotare impressioni, dettagli e follow-up dopo aver contattato o visitato un'agenzia. Per lo stato sintetico usa la colonna `stato` in [`agenzie.csv`](./agenzie.csv); qui invece scrivi il dettaglio.

## Formato suggerito per ogni voce

```
## YYYY-MM-DD — Nome Agenzia
- Contatto: telefono/email/di persona
- Persona: nome referente
- Immobili proposti: indirizzo, prezzo, mq, note
- Impressione generale:
- Prossimi passi:
```
